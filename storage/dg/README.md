# DeviceGame veri klasörü

Bu klasördeki `database.json`, ilk sayfa açılışında otomatik oluşturulur.

- Kullanıcılar ve şifre hash'leri buradadır; klasörü webden erişime kapalı tutun.
- Yedek almak için `database.json` dosyasını kopyalamanız yeterlidir.
- Dosyayı elle düzenlerseniz geçerli JSON olduğundan emin olun.
- `database.lock`, eşzamanlı yazmaları kilitlemek için kullanılır; silinebilir ancak gerekli değildir.
