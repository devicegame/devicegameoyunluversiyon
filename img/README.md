# Ürün görselleri

Buraya ürün kapaklarını koy (örn. `ea-sports-fc-26.jpg`), ardından
`data/products.php` içindeki ilgili kayda `'image' => 'img/ea-sports-fc-26.jpg'`
satırını ekle.

Öneriler: 4:5 veya 1:1 oran, en az 800 px genişlik, JPG/WebP, 300 KB altı.
Dosya yoksa ürün, `lib/art.php` ile üretilen SVG kapakla gösterilir.
